# Estructuras Base de Datos

Este repositorio contiene ejemplos y ejercicios relacionados con estructuras de datos y modelos aplicados a bases de datos. El objetivo es mostrar diferentes implementaciones y análisis utilizando notebooks de Python u otros archivos de herramientas de desarrollo.

## Estructura del repositorio

El repositorio está organizado de la siguiente manera:

* **Arboles y lista/**
  Contiene ejemplos y ejercicios relacionados con estructuras de datos como listas y árboles.

* **Modelo_Hospital/**
  Incluye el desarrollo de un modelo de datos aplicado a un sistema hospitalario.

* **Estructura_de_datos.ipynb**
  Notebook desarrollado en Google Colab donde se realizan pruebas, análisis y ejemplos de estructuras de datos utilizando Python.

## Tecnologías utilizadas

* Python
* Google Colab
* GitHub

## Objetivo del proyecto

Este repositorio fue creado con fines académicos para el estudio y comprensión de estructuras de datos y su aplicación en modelos de información.
